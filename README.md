# EtchASketch

A Python-based drawing application that replicates the classic Etch A Sketch toy, allowing users to draw on a virtual canvas using keyboard controls.

## Features
- Interactive drawing using arrow keys (Up, Down, Left, Right)
- Clear the canvas with a single key press
- Simple and intuitive interface

## Installation
Clone the repository:
git clone https://github.com/DarkKiraOG/EtchASketch.git
cd EtchASketch

Run the application:
python main.py

## Controls
- Use the arrow keys to move the drawing cursor
- Press 'C' to clear the canvas

## Notes
- The application runs in the terminal and requires Python installed.
- Designed for educational purposes and basic drawing tasks.
